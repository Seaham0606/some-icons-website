## Website v3.0.0

This update introduces a major structural upgrade to the SomeIcons website and development architecture.

### Highlights

**Monorepo Architecture**

The project has been reorganized into a modern monorepo structure to better support the growth of the SomeIcons ecosystem. This allows multiple applications and shared resources to live within a single repository while remaining independently deployable.

**Design System Foundation**

A new design system package has been introduced to host shared UI components and design tokens. This lays the groundwork for a consistent visual and interaction system across the website, documentation, and future projects.

**Component Documentation with Storybook**

A dedicated documentation environment has been added using Storybook. This will serve as the public-facing reference for UI components, patterns, and design tokens as the design system evolves.

**Improved Project Scalability**

The new structure prepares the project for future expansion, including:

* a dedicated design system documentation site
* a future marketing site
* shared UI infrastructure across applications

This update focuses on long-term maintainability and scalability while keeping the current icon library experience unchanged.
